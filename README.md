# Analysis-of-Socio-Economic-Factors-Influencing-Adult-Income

## Project Overview

This project analyses the relationship between socio-economic and demographic factors and adult income levels using Python. The analysis focuses on factors such as age, education, workclass, occupation, gender, marital status, working hours, and capital-related attributes.
The project includes data preprocessing, exploratory data analysis, and static and interactive visualizations to identify patterns associated with income levels.

## Objectives

1) Analyse the distribution of adult income levels.
2) Examine the relationship between education, occupation, age, gender, and working hours and income.
3) Perform data cleaning and preprocessing.
4) Identify patterns, outliers, and relationships within the dataset.
5) Present findings through meaningful static and interactive visualizations.


## Dataset

The Adult Income Dataset contains demographic, educational, employment, and financial information about individuals. The target variable represents two income groups: <=50K and >50K.
Source: UCI Machine Learning Repository – Adult Dataset
https://archive.ics.uci.edu/dataset/2/adult

## Key Analysis

1) Data inspection and preprocessing
2) Missing value and duplicate handling

4) Univariate, bivariate, and multivariate analysis

6) Interpretation of socio-economic patterns associated with income
